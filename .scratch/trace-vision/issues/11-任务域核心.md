# 11 — 任务域核心

**What to build:** 任务的完整数据层端到端可用：任务可创建/编辑/暂停/恢复/完成/硬删，状态机按规则自动流转，tasks.json 持久化；renderer 通过 state:tasks 拿到全量推送、通过 task:* invoke 通道完成全部操作。剪贴板存储（items.json）完全不动。

**Blocked by:** None — can start immediately

**Status:** resolved

- [ ] Task 模型（Task/AppRef/ResourceRef/snapshot）与 TaskDto（含 alive）按规格《实现决策 2》的类型形状实现；TaskStore 独立持久化 tasks.json（userData，version 字段，损坏/缺字段安全回退）
- [ ] 状态机全转换表：无归属事件超阈值（默认 15 分钟，可配 1-120）Active→Paused；收到归属事件→Active（Paused 自动恢复）；Waiting/Completed 仅手动；Completed 保留可恢复、硬删+确认、无回收站；多任务可同时 Active
- [ ] 排序：状态分组（Active > Waiting > Paused > Completed），组内 lastActiveAt 降序
- [ ] 类型安全操作：merge（只并同类资源）、link-item/unlink-item、快照生成（文本 preview 200 字符不存全文 / 图片 imageId+宽高+bytes / 文件 paths）；alive 推送时查 ItemStore 计算；去重提升不刷新快照
- [ ] IPC 四文件合约：state:tasks 全量推送 TaskDto[] + task:load/create/update/delete/merge/link-item/unlink-item，typecheck 绿
- [ ] vitest：状态机转换表、排序、merge 类型安全、持久化 round-trip；npm run typecheck + npm test 全绿
