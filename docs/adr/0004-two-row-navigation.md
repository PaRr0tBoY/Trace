# ADR-0004: 两行导航（剪贴板 / 文件 / 任务 + 二级标签）

- 状态：已接受（2026-08-11，grill-with-docs 会话）
- 关联：ADR-0001（sourceApp）、ADR-0002（任务引导流）、ADR-0003（AI 标题）

## 背景

默认视图原为单行 6 chip（全部/文本/链接/图片/文件/任务）。用户要求重构为两行：
第一行三个一级入口，第二行随一级入口切换的二级标签。任务层原为"建议在上、
任务在下"的单滚动列，改为两个二级标签分别查看。文件层引入按后缀动态分类的
二级标签，后缀视图按**文件成员**（组内的单个路径）展示而非按组。

## 决策

### 一级标签（第一行）

`剪贴板 | 文件 | 任务`。剪贴板 = 文本 + 链接 + 图片（含图片文件拖入），
**不含文件条目**；文件 = 非图片文件条目。`TypeFilter` 移除 `'files'`（升级为
一级视图），剩余 `'all' | 'text' | 'links' | 'images'`，且剪贴板视图下
`'all'` 不再含文件。

### 剪贴板二级

`全部（不含文件）| 文本 | 链接 | 图片`。默认停在全部。

### 文件二级（动态）

`全部 + 动态后缀标签 + 其他`：

- 标签集从当前文件条目的路径后缀实时推导（Node `path.extname` 语义：
  `.gitignore` 这类点开头文件算无后缀）。
- 排序按该后缀下的文件数降序；同数按字母序。溢出截断，**保住"全部"和"其他"**
  （无后缀文件只在"其他"与"全部"可见）；标签不带数量角标。
- 没有任何文件条目时，第二行整行隐藏（两行弹簧动画缩回一行）。
- 后缀/其他视图展示**文件成员**（单个文件），全部视图保持组展示。
- 选中标签因文件删光而不存在时，回退到全部。

### 任务二级

`已有任务 | 候选任务`。默认停在已有任务。

- **已有任务** = 所有已创建的任务（任何状态）；active > waiting > paused >
  completed 分组不变，completed 排在尾部。
- **候选任务** = 原"建议"（算法推出的可能任务，未采纳）；卡片动作不变
  （采纳/编辑/忽略/展开原因/拖入绑定）。术语定死：候选任务 / 采纳
  （见 glossary）；不再使用"建议任务"。
- 忽略语义维持现状：签名表按 app 组合 + **1 小时时段槽**，本时段内不再建议，
  下一小时是新会话可再次出现（`ignored.ts` 已实现，零改动）。

### 成员级操作（后缀/其他视图）

后缀视图的单文件卡复用现有成员机制，**不新建剪贴板条目**：

- 复制/粘贴 → `item:copy-subitem` / `item:paste-subitem`（`paths: [单路径]`）：
  写单文件到剪贴板、watcher 暂停防再捕获、只把父条目提升到栈顶。
- 拖出 → `item:start-drag` 单路径请求（`resolveDragData` 合成单文件）。
- 固定与删除是条目级操作：成员卡不提供删除；固定作用于父条目。

### 徽标

- 一级"任务"chip：红角标（paused + waiting 计数），**不显示**琥珀点。
- 二级标签：已有任务 = 红角标；候选任务 = 琥珀点（有候选）。

### 交互默认

- 一级切换时二级选择保留（沿用现 typeFilter 存续语义）。
- 默认二级：剪贴板→全部、文件→全部、任务→已有任务。
- 搜索作用域跟随当前标签（文件按文件名、剪贴板按文本；任务层不搜任务）。

### 初始页面与恢复时间（行为页顶部设置）

**初始页面**（默认 任务→已有任务）：选择展开时默认显示的一级 + 二级页面。
选项：剪贴板→全部/文本/链接/图片；任务→已有任务/候选任务；**文件无二级选项**
（二级固定"全部"）——动态后缀与"其他"都可能在内容变化后不存在，不可作为
初始页面目标。

**恢复时间**（默认 稍缓 10s）：四档 `立刻 0s / 稍缓 10s / 延时 10min / 持久 ∞`，
每档同列小字解释（0s = 收回后即恢复初始页面；∞ = 一直保持上次收回时的页面，
初始页面无效）。

- 机制：以**面板收回时刻**为锚。TTL 内再展开 → 保留上次页面（一级 + 二级 +
  设置子页，含变更日志）；超时 → 恢复初始页面。展开状态下切换标签不触发恢复。
- 重置范围：一级/二级、设置子页、搜索词、任务详情与确认框（回列表）。
- **编辑保护**：新建/编辑任务表单或候选卡内联标题编辑激活时，跳过整个恢复
  （编辑状态绝不因恢复而丢失）。
- 选"持久"时初始页面选择器置灰。
- 首次启动（含持久模式）先应用初始页面设置；教程进行中不触发恢复。

## 考虑过的选项

- **任务左右两列**：270px 面板下每列约 130px，两行布局的建议卡放不下操作
  按钮；且"看建议看不到任务"的切换诉求恰是分列要解决的。→ 二级标签。
- **复制成员 = 新建单文件条目**：历史被近重复条目污染，且去重签名不同无法
  合并。→ 复用 copy-subitem 的"只提升父条目"语义。
- **忽略永久生效**：用户否决——当下无效不代表以后无效。→ 维持 1 小时槽。

## 后果

- header 高度 40px → 约 62px（两行 chips）；文件二级行会随内容增删/重排。
- i18n 新增键：剪贴板 / 已有任务 / 候选任务 / 其他 / 初始页面 / 恢复时间四档
  及解释（30 语言）；后缀标签文案即后缀本身（小写无点），全语言通用不翻译。
- 教程（onboarding step 4 指向文件卡）与新空态需同步新结构。
- 无持久化结构改动：文件成员 = `paths[]` 下标；二级选择为 renderer 状态。
- Settings 行为/位置/外观 子页标签从局部 useState 提进 store（记忆与恢复的
  前提）；任务编辑状态与候选卡编辑标志需 store 可见（编辑保护的前提）。
- `Settings` 新增字段：landing（一级+二级，文件无二级）、restoreTime
  （instant/relaxed/delayed/forever）；settings.ts merge 钳制。
