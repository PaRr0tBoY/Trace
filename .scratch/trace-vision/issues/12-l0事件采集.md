# 12 — L0 事件采集

**What to build:** 系统开始记录前台应用/窗口切换：main 进程每 500ms 轮询一次，前台窗口变化时生成 app-switch 事件进事件总线与内存环形缓冲（上限 1000，不持久化）；设置里新增"任务采集"区——总开关、L0 开关（默认开）、incognito 联动暂停。

**Blocked by:** None — can start immediately

**Status:** resolved

- [ ] koffi 轮询 GetForegroundWindow（GetWindowTextW / GetWindowThreadProcessId / QueryFullProcessImageNameW，沿用全屏检测基建），前台窗口变化生成 `{type:'app-switch', appName, exePath, pid, windowTitle, ts}`；同一窗口不重复发事件
- [ ] 事件总线：消费者可订阅（归属器/事件日志）；内存环形缓冲上限 1000 条，不持久化，重启即清
