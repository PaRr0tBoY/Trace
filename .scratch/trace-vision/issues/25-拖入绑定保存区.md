# 25 — 拖入绑定：保存区 + 任务列表

**What to build:** OS 文件/文字拖入面板时，DropOverlay（"Drop to save"）换成：顶栏固定"保存区"（拖入 = 存剪贴板栈，不挂任务）+ 一页任务列表（放得下多少放多少，不够补备选卡）。拖到任务 = 绑定；拖到备选卡 = 自动创建真实任务并绑定；拖到保存区 = 按现状保存。

**Blocked by:** 23（备选卡）、26（APP 图标）

**Status:** open

- [ ] DropOverlay 重设计：顶部保存区落点（拖入即 splitItem/保存，现 onDrop 逻辑）+ 可滚动任务列表（全部任务一页，状态点+标题+图标）；无任务且无备选时退回现状 Drop to save 提示
- [ ] 拖到任务卡：link（现状 TaskDropBar linkDraggedItem 逻辑复用，含 elementFromPoint 解析路径）
- [ ] 拖到备选卡：main 侧新建任务（标题取备选标题）并 link 拖入内容，备选卡从列表移除
- [ ] OS 文件（DragEvent Files）拖到任务卡：文件路径直接 link 进任务（ResourceRef files），需确认/新增 task:* IPC
- [ ] 触发条件统一：dragActive（OS 拖入）或 internalDragReq（剪贴板条目拖拽）都显示该面板；剪贴板视图与任务视图行为一致
- [ ] 拖拽期间面板不关闭（沿用现有 drag 感知）；drop 后 UI 状态清零（internalDragReq/dragActive）
- [ ] typecheck + npm test 全绿；真机：文件拖到任务、文字拖到任务、拖到备选自动建任务、拖到保存区三态
