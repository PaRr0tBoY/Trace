# 16 — 聚类管线

**What to build:** 事件批 → 段 → 任务归属的纯算法判定：事件批先段化（时间间隙硬切分 + 相邻段应用重叠率软切分 + 瞬时切换并入），再按任务质心摘要增量归属（并入 vs 新建），输出 best/margin 双判据三区置信度。这是全系统风险最高的纯逻辑模块。

**Blocked by:** 11（任务域核心）、12（L0 事件采集）

**Status:** resolved

- [ ] 规则预筛：事件批 app 名与任务 AppRef 重叠 → 候选任务集（先于算法）
- [ ] 段化：时间间隙硬切分（默认 ~8-10 分钟）+ 相邻段应用重叠率软切分 + <2-3s 瞬时切换并入邻段（纯超时不够，必须三信号齐备）
- [ ] 增量簇归属：每任务加权质心摘要（应用计数向量 + 标题 token 频次，可选本地 embedding 通道，缺失时纯 token 重叠降级）；余弦/Jaccard 阈值判定并入 vs 新建
- [ ] 置信度 = best/margin 双判据三区制（≥θ_high 高置信并入 / θ_low~θ_high 低置信待确认 / <θ_low 新建候选）；阈值可配
- [ ] 归属结果结构含算法证据（app 组合/时长/重叠任务），供上层展示与 LLM 标注
- [ ] vitest 合成事件流（本票测试占全系统大头）：切分边界、瞬时并入、跨任务切分（"查资料 20 分钟回写代码"类场景归回原任务）、簇归属阈值、三区、embedding 缺失降级；typecheck + npm test 全绿
