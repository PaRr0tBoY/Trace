# 20 — 长期记忆系统

**What to build:** 记忆库端到端：任务系统反馈自动沉淀记忆候选 → 记忆面板 [保存]/[忽略]/[永久禁止] → confirmed 记忆按衰减公式演化 → context-prior 注入建议引擎（标题贴合用户术语、置信度提升）。

**Blocked by:** 19（建议引擎集成）

**Status:** resolved

- [ ] memories.json 持久化（version 字段，同 tasks.json 模式）；四类记忆（identity/tool/project/workflow）；Memory 形状按规格内联类型（含 source / userState / confidence / hitCount）
- [ ] 反馈分流：任务确认的标题、忽略的模式自动沉淀为 suggested 候选（source: 'task-feedback'）——仍需用户确认才成为 confirmed；无独立检测管线
- [ ] 记忆面板（设置内）：候选列表 + [保存]/[忽略]/[永久禁止]；banned 表关键词/类型匹配，之后同类不再提议
- [ ] 强化/衰减：conf = sat(hitCount) × exp(-λΔt)（λ 周级）；超期未命中降权；低分进清理候选（用户确认后删除）；阈值进设置（默认值标注依据）
- [ ] context-prior：命中任务/事件的记忆（project/workflow）注入 19 的分析输入——提升置信度、标题贴合用户术语（LLM 辅助层输入的一部分）
- [ ] embedding 通道可选（复用 16 的选型，本地模型），缺失时纯文本/规则检索降级
- [ ] vitest：四类写入、suggested→confirmed/ignored/banned 流转、banned 匹配、衰减公式（注入时钟）、清理候选；typecheck + npm test 全绿；dev 手动验证（确认任务 → 候选出现 → 保存后建议标题贴合）
