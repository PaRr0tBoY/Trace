# Trace 领域术语表

任务系统与剪贴板领域的关键术语。随 ADR 演进维护，只写当前生效的定义。

| 术语 | 定义 |
|---|---|
| 任务（Task） | 一段聚焦工作的单元：标题 + 关联应用（apps）+ 关联素材（resources）+ 状态机（active/paused/waiting/completed）。 |
| 应用（App，口语"进程"） | 窗口跟踪捕捉到的程序，身份键 = 小写规范化 exePath（无 exePath 时退回进程名）。UI 上显示为图标 + 显示名。 |
| AppRef | 应用的领域引用：id（身份键）+ name + exePath + 图标 dataURL + 最近上下文。 |
| sourceApp | 剪贴板条目的来源应用（捕获瞬间的前台快照），随条目持久化（ADR-0001）。 |
| 窗口跟踪（L0） | foreground watcher 每 500ms 轮询前台窗口，产生 AppSwitchEvent 的采集层；剪贴板归属与它同源同门控。 |
| 事件总线（eventBus） | 内存环形缓冲，承载 AppSwitchEvent / ClipboardEvent；有界、重启清空。 |
| 资源（ResourceRef） | 任务关联的素材：clipboard（条目快照）或 files（路径列表）。 |
| 资源快照（ResourceSnapshot） | 关联瞬间的内容摘录：文本 200 字预览 / 图片身份与尺寸 / 文件路径。条目被驱逐后任务详情仍可显示。 |
| 渐进式披露 | 引导流的披露层级：默认 3 条剪贴板 → 选中进程后出现该进程条目 → 显示更多 +3 条至 15 条封顶。 |
| 锚点三条 | 剪贴板列表的固定头部：全局最近 3 条（任意进程），选中进程后仍然置顶。 |
| AI 标题生成 | 保存按钮的隐含步骤：标题为空但有上下文时，用标题+进程+剪贴板+备注+命中记忆向 LLM 请求 1-3 个候选，取最佳保存。 |
| 算法标题 | LLM 不可用时的降级标题（"X + Y task"），与建议引擎同源。 |
| 记忆（Memory） | 长时记忆条目，类型 identity/tool/project/workflow；仅 confirmed 的 project/workflow 会进 AI 上下文。 |
| 记忆上下文（memoryContext） | 与当前输入相关的 confirmed 记忆片段，注入 LLM payload 供标题贴合用户术语。 |
| 归属（Attribution） | 前台事件 → 任务的自动关联：匹配 AppRef 即 resume/刷新；剪贴板自动归属（t14）是它的分支。 |
| 剪贴板视图（Clipboard view） | 一级标签"剪贴板"下的内容：文本、链接、图片（含图片文件拖入）。**不含文件条目**——文件在文件视图中。 |
| 文件视图（Files view） | 一级标签"文件"下的内容：非图片文件条目。 |
| 图片文件（Image files） | 路径全是图片后缀的文件条目；分类上算图片，不算文件，出现在剪贴板视图而不在文件视图。 |
| 候选任务（CandidateTask） | 算法从窗口/剪贴板信号推出的可能任务；**不是任务**——无状态机、无资源，未被采纳前只在候选列表。口语曾称"建议"。 |
| 采纳（Adopt） | 候选任务 → 任务的转换动作（main 侧创建 Task）；拖资源到候选卡上 = 采纳并绑定（accept-with-resource）。 |
| 已有任务（ExistingTasks） | 任务层二级标签之一：所有已创建的任务（任何状态），completed 排在列表尾部。曾称"正在进行"。 |
| 忽略（Ignore） | 候选卡上的 ✕：把"app 组合 + 1 小时时段"签名写进忽略表，该组合在本时段内不再被建议；下一小时是新会话，可再次出现。 |
| 文件成员（File member） | 文件条目 `paths[]` 中的单一路径。后缀/其他视图按成员展示与操作：复制/粘贴/拖出作用于该单文件且**不新建条目**（复用 copy-subitem）；固定与删除是条目级操作。 |
| 后缀标签（Extension tab） | 文件视图的二级标签：全部 + 按当前内容动态推导的后缀标签（数量降序、溢出截断）+ 其他（无后缀条目）。后缀视图显示文件成员，全部视图显示组。 |
| 初始页面（Landing page） | 设置中选定的默认展开页面（一级 + 二级；文件与笔记一级固定二级为全部）。恢复时间到期后展开时回到此页。 |
| 智能收起（Smart collapse） | 行为设置（默认开）：被动信号（光标离开 + 编辑 idle 5s、外部滚动、外部复制、锁屏/睡眠、前台离开）自动收起面板或放弃切换器会话；关闭后仅 Esc / 点击外部等主动操作收起。 |
| 自动聚焦（Auto-focus） | 行为设置（默认开）：进入笔记页自动聚焦编辑器；关闭 = 打开即读，点击编辑器才开始编辑（切换器搜索框始终聚焦）。 |
| 恢复时间（Restore time） | 面板收回后保留上次页面状态的最长时长。四档：立刻 0s / 稍缓 10s / 延时 10min / 持久 ∞；超时后展开回到初始页面，持久则初始页面不生效。 |
| 编辑保护（Edit protection） | 恢复机制的例外规则：新建/编辑任务表单或候选卡内联标题编辑激活时，跳过恢复，编辑状态不丢失。 |
